Política de Privacidade

1. Finalidade desta página

A landing page Alma Docente coleta dados de pessoas interessadas em receber o e-book gratuito e comunicações diretamente relacionadas à campanha para profissionais da educação.

2. Dados coletados

Podemos coletar nome, e-mail, WhatsApp, área de atuação na educação, resposta opcional sobre o momento profissional, consentimento e parâmetros de campanha (UTMs).

3. Como os dados são utilizados

Os dados são utilizados para registrar o pedido do material, organizar a base de contatos, viabilizar a entrega do e-book e enviar comunicações relacionadas à iniciativa Alma Docente.

4. Armazenamento

Os dados enviados pelo formulário são registrados em uma base do Google Sheets conectada à campanha. O acesso à base é restrito aos responsáveis pela operação do projeto.

5. Compartilhamento e venda

Os dados não são vendidos. Poderão ser processados por serviços técnicos necessários para hospedagem, formulários, armazenamento e envio de comunicações, dentro das finalidades descritas nesta política.

6. Consentimento e cancelamento

Ao marcar o campo de consentimento, você autoriza o uso dos dados para as finalidades informadas. Essa autorização pode ser revogada a qualquer momento mediante solicitação pelos canais de contato do projeto.

7. Atualizações

Esta política pode ser atualizada para refletir melhorias na campanha ou mudanças nos serviços utilizados. A versão publicada nesta página será considerada a versão vigente.
